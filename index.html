Section 01

What is a CSS Selector?

A CSS Selector is the pattern or expression placed before a CSS declaration block that tells the browser engine which HTML element(s) on the page should receive the specified design rules.

Anatomy of a CSS Rule
Selector .btn-primary:hover
{
Property background-color : Value #4f46e5 ;
}

The 5 Foundational Basic Selectors

Every stylesheet builds upon these five essential building blocks:

*

Universal Selector

Matches every single element within the entire document tree.

* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
Specificity: 0-0-0 Universal Resets
tag

Element / Type Selector

Matches all instances of a specified HTML element node.

p {
    font-size: 16px;
    line-height: 1.6;
    color: #334155;
}
Specificity: 0-0-1 Base Typography
.class

Class Selector

Matches elements having the specified class name. Can be reused freely across elements.

.card-feature {
    background: #ffffff;
    border-radius: 12px;
    padding: 24px;
}
Specificity: 0-1-0 Reusable UI Components
#id

ID Selector

Matches a single unique element with the exact matching id attribute.

#main-navigation {
    position: sticky;
    top: 0;
    z-index: 1000;
}
Specificity: 1-0-0 Unique Landmarks
A, B

Grouping Selector (Comma)

Applies identical declarations to multiple distinct selectors separated by commas.

h1, h2, h3, h4 {
    font-family: 'Plus Jakarta Sans', sans-serif;
    color: #0f172a;
    font-weight: 700;
}
Specificity: Per selector DRY Stylesheet

    Section 03

    Attribute Selectors

    Attribute selectors match elements based on the presence, exact value, or substring pattern of any HTML attribute (such as type, href, target, disabled, or custom data-* attributes).

    Pattern Name & Logic Real-World Code Example Typical Use Case
    [attr] Attribute Presence: Element possesses the attribute regardless of its value. input[required] { border-color: #f59e0b; } Highlighting mandatory form inputs
    [attr="val"] Exact Match: Attribute value is identical to the specified string. input[type="email"] { padding-left: 36px; } Specific form input controls
    [attr^="val"] Prefix / Starts With: Value begins with the specified string. a[href^="https://"] { color: #0284c7; } Styling secure external links
    [attr$="val"] Suffix / Ends With: Value terminates with the specified string. a[href$=".pdf"]::after { content: " 📄"; } Auto-detecting downloadable files
    [attr*="val"] Substring / Contains: Value contains the string anywhere inside. [class*="icon-"] { vertical-align: middle; } Matching icon class families
    [attr~="val"] Whitespace List: Matches value in a space-separated list. [data-tags~="frontend"] { font-weight: bold; } Tag filtering systems
    ⚡
    Pro Tip: All attribute selectors have the exact same specificity as a class selector: 0-1-0! You can combine attributes with pseudo-classes like input[type="text"]:focus.
    Section 04

    Pseudo-Classes: State & Tree Position

    A pseudo-class (prefixed with a single colon :) selects elements based on their current state, user interaction, or index position in the document tree.

    1. User Interaction & State

    • :hover — Triggered when user hovers cursor over an element.
    • :focus — Triggered when an element (input/button) receives keyboard/click focus.
    • :focus-visible — Triggers focus ring strictly for keyboard navigation (Accessibility standard).
    • :active — Triggered the moment an element is actively clicked/pressed down.
    • :visited — Styles hyperlinks that the user has already visited in browser history.

    2. Structural & Index Selectors

    • :first-child — The very first sibling element under its parent.
    • :last-child — The very last sibling element under its parent.
    • :nth-child(n) — Matches by mathematical formula (e.g. 2n, even, odd, 3).
    • :nth-of-type(n) — Matches the nth sibling of the exact same tag type.
    • :only-child — Matches only if the parent contains no other children.

    3. Form & Functional Pseudo-Classes

    • :checked — Applied to active radio buttons, checkboxes, or options.
    • :disabled — Applied to non-interactive form controls with disabled attribute.
    • :required / :optional — Applied based on presence of form validation flags.
    • :valid / :invalid — Triggered dynamically when form inputs pass/fail HTML5 pattern rules.
    • :not(selector) — Negation pseudo-class: styles elements that DO NOT match the inside argument.

    Section 05

    Pseudo-Elements: Virtual DOM Sub-Parts

    A pseudo-element (prefixed with double colons ::) targets a specific sub-part of an element or generates virtual content without adding extra HTML tags.

    ::before

    Virtual Lead Content

    Creates a virtual pseudo-box as the very first child of the element. Requires the content: "" property.

    .badge::before {
    content: "★";
    margin-right: 6px;
    color: #eab308;
}
    ::after

    Virtual Trailing Content

    Creates a virtual pseudo-box as the last child. Ideal for decorative underline animations, badges, or clearfixes.

    .link-animated::after {
    content: "";
    display: block;
    height: 2px;
    background: #4f46e5;
}
    ::placeholder

    Form Hint Styling

    Styles the muted placeholder text inside <input> and <textarea> elements.

    input::placeholder {
    color: #94a3b8;
    font-style: italic;
}
    ::selection

    User Text Highlight

    Customizes the background and text color when a user highlights text on your page.

    ::selection {
    background-color: #6366f1;
    color: #ffffff;
}
    Section 06

    The CSS Specificity Matrix

    When multiple conflicting CSS rules target the same element, the browser calculates each selector's Specificity Score. The rule with the highest score wins the cascade!

    Inline Style 1 - 0 - 0 - 0 1000 points style="color: red;"
    >
    ID Selectors 0 - 1 - 0 - 0 100 points #header, #hero-btn
    >
    Classes, Attrs, Pseudo 0 - 0 - 1 - 0 10 points .btn, [type="text"], :hover
    >
    Elements & Pseudo-Elems 0 - 0 - 0 - 1 1 point div, p, h1, ::before
    p 0 - 0 - 0 - 1 (1 pt) Single element selector
    div p 0 - 0 - 0 - 2 (2 pts) Two element selectors
    .card p 0 - 0 - 1 - 1 (11 pts) One class + one element
    .card .title:hover 0 - 0 - 3 - 0 (30 pts) Two classes + one pseudo-class
    #main-hero .btn 0 - 1 - 1 - 0 (110 pts) One ID + one class
    #nav .list > li:first-child a 0 - 1 - 2 - 2 (122 pts) 1 ID, 1 class, 1 pseudo-class, 2 elements
    ⚠️
    The Nuclear Option: !important
    Appending !important overrides normal specificity completely. Use it sparingly for accessibility utility classes; never use it to fix poor selector specificity architecture!

    Section 09

    Quick Reference & Best Practices

    1

    Favor Classes for Styling

    Keep your CSS maintainable by styling via classes (.btn, .card). Avoid over-relying on IDs (#btn) which inflate specificity.

    2

    Keep Selectors Shallow

    Avoid deep nesting like div.wrapper > div > ul > li > a > span. Aim for 1-2 levels of specificity to keep rules easy to override.

    3

    Leverage Combinators

    Use child combinators (>) when child isolation is needed, and sibling combinators (+, ~) for rhythmic content spacing.

    4

    Respect the Cascade

    Resolve specificity issues by lowering high-specificity rules instead of slapping !important onto declarations.
