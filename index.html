Section 01

What is CSS Flexbox?

The Flexible Box Module (Flexbox) is a one-dimensional layout system designed to align, distribute, and proportion space among items in a container, even when their sizes are unknown or dynamic.

💡 Why "One-Dimensional"? Flexbox deals with layout along a single dimension at a time — either as a horizontal row or as a vertical column. (For simultaneous 2D grids, CSS Grid is used).

The Core Hierarchy: Flex Container vs. Flex Items

Everything in Flexbox is built upon a parent-child relationship:

display: flex Container

Creates a block-level flex container. The container expands to fill 100% of the available parent width.

.container {
    display: flex;
}
display: inline-flex Container

Creates an inline-level flex container. The container only takes up as much width as its children require.

.container-inline {
    display: inline-flex;

Section 03

Flex Container Properties (Parent)

These rules are applied to the parent element to control the layout, flow, alignment, and spacing of all its direct children.

flex-direction Parent

Establishes the main-axis direction. Values: row (default), row-reverse, column, column-reverse.

.container {
    flex-direction: row; /* or column */
}
flex-wrap Parent

Controls whether flex items are forced onto a single line or can wrap onto multiple lines. Values: nowrap, wrap, wrap-reverse.

.container {
    flex-wrap: wrap; /* allows multi-line */
}
flex-flow Shorthand

Combines flex-direction and flex-wrap into a single convenient declaration.

.container {
    /* <direction> <wrap> */
    flex-flow: row wrap;
}
justify-content Main Axis

Aligns items along the Main Axis. Values: flex-start, center, flex-end, space-between, space-around, space-evenly.

.container {
    justify-content: space-between;
}
align-items Cross Axis

Aligns items along the Cross Axis for the current line. Values: stretch (default), flex-start, center, flex-end, baseline.

.container {
    align-items: center;
}
align-content Multi-Line

Aligns multi-line flex tracks along the cross axis. Only active when flex-wrap: wrap is set and items wrap onto 2+ lines.

.container {
    align-content: space-around;
}
gap (row-gap, col-gap) Spacing

Defines precise gutters between flex items without annoying margin-reset hacks on first/last items!

.container {
    gap: 1.5rem; /* row & col gap */
}
Section 04

Flex Item Properties (Children)

These properties are applied directly to individual child elements to define how each item sizes, shrinks, grows, or aligns relative to its siblings.

order Child Item

Controls the visual render order independently of the source HTML. Default is 0. Accepts positive and negative numbers.

.item-first {
    order: -1; /* jumps to start */
}
flex-grow Child Item

Defines an item's ability to grow to absorb remaining free space along the main axis. Default: 0 (does not grow).

.item-expand {
    flex-grow: 1; /* fills space */
}
flex-shrink Child Item

Defines an item's ability to shrink when space is restricted. Default: 1. Set to 0 to prevent squishing.

.avatar-icon {
    flex-shrink: 0; /* never squish */
}
flex-basis Child Item

Sets default initial size of an item before space distribution. Accepts px, %, rem, or auto.

.sidebar {
    flex-basis: 260px;
}
flex (Shorthand) Recommended

Shorthand for flex-grow, flex-shrink, and flex-basis combined. E.g. flex: 1 1 200px;.

.card {
    /* <grow> <shrink> <basis> */
    flex: 1 1 250px;
}
align-self Cross Axis

Overrides the container's align-items value for this single item. Values: auto, flex-start, center, flex-end, stretch.

.special-child {
    align-self: flex-end;
}

🎯 Perfect Center

Horizontally & vertically centered with 2 lines of CSS!

Why it works: Setting justify-content: center centers items along the main axis (X), while align-items: center centers items along the cross axis (Y).
HTML Structure
<div class="center-container">
    <div class="card">
        <h4>Perfect Center</h4>
    </div>
</div>
CSS Stylesheet
.center-container {
    display: flex;
    justify-content: center; /* X-axis */
    align-items: center;     /* Y-axis */
    min-height: 220px;
}

Section 07

Flexbox Quick Reference & Cheat Sheet

A fast reference guide for all container and item properties.

Target Property Default Available Values Description
Container display block flex, inline-flex Activates flexbox context for direct children.
Container flex-direction row row, row-reverse, column, column-reverse Defines the direction of the Main Axis.
Container flex-wrap nowrap nowrap, wrap, wrap-reverse Allows flex items to break into multiple lines.
Container justify-content flex-start flex-start, center, flex-end, space-between, space-around, space-evenly Aligns items along the Main Axis.
Container align-items stretch stretch, flex-start, center, flex-end, baseline Aligns items along the Cross Axis on the current line.
Container gap 0 <length> (e.g. 16px, 1rem) Gutter spacing between adjacent flex items.
Child Item order 0 <integer> (e.g. -1, 0, 2) Controls visual order independent of HTML order.
Child Item flex-grow 0 <number> (e.g. 0, 1, 2) Proportional ability to grow and take free space.
Child Item flex-shrink 1 <number> (e.g. 0, 1) Proportional ability to shrink when space is tight.
Child Item flex-basis auto auto, <length> (e.g. 200px) Initial base size before distributing space.
Child Item align-self auto auto, flex-start, center, flex-end, stretch Overrides parent's align-items for this item.
